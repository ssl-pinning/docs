Konfiguracija servera ​

Server učitava konfiguraciju iz nekoliko izvora, po rastućem prioritetu: podrazumevane vrednosti, konfiguracioni fajl, promenljive okruženja, zatim parametri komandne linije.

Sekcije ​

SekcijaOpis
keysKonfiguracija ključeva domena
logPodešavanja logovanja
serverParametri HTTP servera
storageKonfiguracija skladišnog backend-a
tlsTLS/kriptografska podešavanja

log. ​

KljučTipPodrazumevanoOpis
log.formatstringjsonFormat izlaza logova (json, text)
log.levelstringinfoNivo detaljnosti logova (debug, info, warn, error)
log.prettybooleanfalseUključiti formatiran izlaz logova

server. ​

KljučTipPodrazumevanoOpis
server.listenstring127.0.0.1:7500Adresa i port na kom HTTP server sluša
server.read_timeoutduration5sMaksimalno trajanje čitanja celog zahteva
server.write_timeoutduration5sMaksimalno trajanje do timeout-a pri upisu odgovora

storage. ​

KljučTipPodrazumevanoOpis
storage.typestringmemorymemory, redis, postgres ili filesystem
storage.dsnstringnemaConnection string — redis://user:password@localhost:6379/0?maintnotifications=disabled ili postgres://user:password@localhost:5432/ssl_pinning?sslmode=disable
storage.dump_dirstring/tmpDirektorijum za fajlovske dump-ove perzistencije
storage.conn_max_idle_timeduration5mMaksimalno vreme neaktivnosti konekcija ka bazi
storage.conn_max_lifetimeduration30mMaksimalan životni vek konekcija ka bazi
storage.max_idle_connsinteger5Maksimum neaktivnih konekcija ka bazi
storage.max_open_connsinteger5Maksimum otvorenih konekcija ka bazi

tls. ​

KljučTipPodrazumevanoOpis
tls.dirstring{config-path}/tlsDirektorijum sa prv.pem i pub.pem
tls.dump_intervalduration5sInterval periodičnog ponovnog potpisivanja registra
tls.timeoutduration5sTimeout TLS operacija ka praćenim domenima

Konfiguracioni fajl ​

yaml
keys:
  - fqdn: example.com

  - fqdn: foo.example.com
    domainName: foo.example.com
    file: example.com.json

  - fqdn: bar.example.com
    file: example.com.json

log:
  format: json
  level: info
  pretty: false

server:
  listen: 0.0.0.0:7500
  read_timeout: 5s
  write_timeout: 5s

storage:
  type: postgres
  dsn: postgres://user:password@localhost:5432/ssl_pinning?sslmode=disable
  conn_max_idle_time: 5m
  conn_max_lifetime: 30m
  max_idle_conns: 5
  max_open_conns: 5

tls:
  dir: /etc/app/tls
  dump_interval: 30s
  timeout: 10s

Promenljive okruženja ​

UPPER_SNAKE_CASE, . se zamenjuje sa _, sa prefiksom SSL_PINNING_:

bash
export SSL_PINNING_LOG_LEVEL=debug
export SSL_PINNING_SERVER_LISTEN=0.0.0.0:7500
export SSL_PINNING_SERVER_READ_TIMEOUT=5s
export SSL_PINNING_SERVER_WRITE_TIMEOUT=5s
export SSL_PINNING_STORAGE_TYPE=postgres
export SSL_PINNING_STORAGE_DSN="postgres://user:pass@localhost:5432/db?sslmode=disable"
export SSL_PINNING_STORAGE_DUMP_DIR=/opt/ssl-pinning/storage-dump
export SSL_PINNING_STORAGE_CONN_MAX_IDLE_TIME=5m
export SSL_PINNING_STORAGE_CONN_MAX_LIFETIME=30m
export SSL_PINNING_STORAGE_MAX_IDLE_CONNS=5
export SSL_PINNING_STORAGE_MAX_OPEN_CONNS=5
export SSL_PINNING_TLS_DIR=/opt/ssl-pinning/tls
export SSL_PINNING_TLS_DUMP_INTERVAL=1s
export SSL_PINNING_TLS_TIMEOUT=3s

  --log-level=debug \
