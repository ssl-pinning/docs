Конфигурация сервера ​

Сервер загружает конфигурацию из нескольких источников, по возрастанию приоритета: значения по умолчанию, файл конфигурации, переменные окружения, затем флаги командной строки.

Секции ​

СекцияОписание
keysКонфигурация ключей доменов
logНастройки логирования
serverПараметры HTTP-сервера
storageКонфигурация бэкенда хранения
tlsTLS/криптографические настройки

log. ​

КлючТипПо умолчаниюОписание
log.formatstringjsonФормат вывода логов (json, text)
log.levelstringinfoУровень детализации логов (debug, info, warn, error)
log.prettybooleanfalseВключить форматированный вывод логов

server. ​

КлючТипПо умолчаниюОписание
server.listenstring127.0.0.1:7500Адрес и порт прослушивания HTTP-сервера
server.read_timeoutduration5sМаксимальная длительность чтения всего запроса
server.write_timeoutduration5sМаксимальная длительность до таймаута записи ответа

storage. ​

КлючТипПо умолчаниюОписание
storage.typestringmemorymemory, redis, postgres или filesystem
storage.dsnstringнетСтрока подключения — redis://user:password@localhost:6379/0?maintnotifications=disabled или postgres://user:password@localhost:5432/ssl_pinning?sslmode=disable
storage.dump_dirstring/tmpДиректория для файловых дампов персистентности
storage.conn_max_idle_timeduration5mМаксимальное время простоя соединений с БД
storage.conn_max_lifetimeduration30mМаксимальное время жизни соединений с БД
storage.max_idle_connsinteger5Максимум простаивающих соединений с БД
storage.max_open_connsinteger5Максимум открытых соединений с БД

tls. ​

КлючТипПо умолчаниюОписание
tls.dirstring{config-path}/tlsДиректория с prv.pem и pub.pem
tls.dump_intervalduration5sИнтервал периодической переподписи реестра
tls.timeoutduration5sТаймаут TLS-операций к отслеживаемым доменам

Файл конфигурации ​

yaml
keys:
  - fqdn: example.com

  - fqdn: foo.example.com
    domainName: foo.example.com
    file: example.com.json

  - fqdn: bar.example.com
    file: example.com.json

log:
  format: json
  level: info
  pretty: false

server:
  listen: 0.0.0.0:7500
  read_timeout: 5s
  write_timeout: 5s

storage:
  type: postgres
  dsn: postgres://user:password@localhost:5432/ssl_pinning?sslmode=disable
  conn_max_idle_time: 5m
  conn_max_lifetime: 30m
  max_idle_conns: 5
  max_open_conns: 5

tls:
  dir: /etc/app/tls
  dump_interval: 30s
  timeout: 10s

Переменные окружения ​

UPPER_SNAKE_CASE, . заменяется на _, с префиксом SSL_PINNING_:

bash
export SSL_PINNING_LOG_LEVEL=debug
export SSL_PINNING_SERVER_LISTEN=0.0.0.0:7500
export SSL_PINNING_SERVER_READ_TIMEOUT=5s
export SSL_PINNING_SERVER_WRITE_TIMEOUT=5s
export SSL_PINNING_STORAGE_TYPE=postgres
export SSL_PINNING_STORAGE_DSN="postgres://user:pass@localhost:5432/db?sslmode=disable"
export SSL_PINNING_STORAGE_DUMP_DIR=/opt/ssl-pinning/storage-dump
export SSL_PINNING_STORAGE_CONN_MAX_IDLE_TIME=5m
export SSL_PINNING_STORAGE_CONN_MAX_LIFETIME=30m
export SSL_PINNING_STORAGE_MAX_IDLE_CONNS=5
export SSL_PINNING_STORAGE_MAX_OPEN_CONNS=5
export SSL_PINNING_TLS_DIR=/opt/ssl-pinning/tls
export SSL_PINNING_TLS_DUMP_INTERVAL=1s
export SSL_PINNING_TLS_TIMEOUT=3s

bash
ssl-pinning up \
  --log-level=debug \
  --storage-type=postgres \
  --storage-dump-interval=30s
