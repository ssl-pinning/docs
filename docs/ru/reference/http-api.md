# HTTP API

| Эндпоинт | Описание |
|---|---|
| `GET /api/v1/{file}` | Подписанный JSON с текущими пинами для доменов, привязанных к `{file}` |
| `GET /health/liveness` | Liveness-проба |
| `GET /health/readiness` | Readiness-проба |
| `GET /health/startup` | Startup-проба |
| `GET /metrics` | Метрики Prometheus, отдаются на отдельном порту (фиксированный `9090`, не настраивается) |
| `/ui/` | Веб-админка: статус пинов и информация о лицензии. Доступна только на тире Pro и выше |

## `GET /api/v1/{file}`

Возвращает [подписанный реестр](./registry-format) для доменов, настроенных на запись в `{file}`. Несколько доменов могут делить один файл через опцию конфига `keys[].file` (см. [Конфигурацию сервера](./server-configuration)) — в этом случае один запрос возвращает пины для всех них.

```bash
$ curl https://ssl-pinning.example.com/api/v1/google.com.json
```

```json
{
  "payload": {
    "keys": [
      {
        "date": "2026-03-24T23:39:22.964574+01:00",
        "domainName": "www.google.com",
        "expire": 4736419,
        "fqdn": "google.com",
        "key": "b8tZqtqfv0RVKfwivfzaXuFWFHkYP4ufBhb5esciCwo="
      }
    ]
  },
  "signature": "Zl8cwtiAoEjvdmFXReiioVk3zUM2ymbQGa2hIxvixNR3..."
}
```

Клиент обязан проверить `signature` прежде чем доверять `payload` — точные шаги проверки в разделе [Архитектура → Криптографическая цепочка](../guide/architecture#криптографическая-цепочка).

## Health-пробы

Стандартные Kubernetes-style пробы, каждая возвращает `200 OK` в здоровом состоянии:

- `/health/liveness` — процесс работает и не завис в deadlock.
- `/health/readiness` — сервер в данный момент может обслуживать запросы к реестру (бэкенд хранения доступен).
- `/health/startup` — последовательность первоначального старта (генерация ключей, подключение к хранилищу) завершена.

## `/metrics`

Метрики в формате Prometheus, отдаются на отдельном порту (фиксированный `9090`, независимо от `server.listen`; не настраивается через конфиг), чтобы скрейпинг не делил listener с прикладным трафиком.

## `/ui/`

На тире Pro и выше сервер дополнительно отдаёт информационную панель по этому пути — статус пинов по доменам и информация о лицензии, защищено отдельным admin-токеном.
